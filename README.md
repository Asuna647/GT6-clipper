# GT6 Clipper — Local GPU Auto-Clipping Studio

Zero-API-cost short-form video clipping pipeline powered by **Faster-Whisper**, **FFmpeg NVENC**, **OpenCV**, and **Streamlit**.

## Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Launch Web Studio: `streamlit run dashboard.py` (or double-click `Start_Clipper_UI.bat`)
3. Open `http://localhost:8501` in your browser.
